# Dota Spyfall
Готовая мини-игра для Discord/удалённой игры.
- 125 героев Dota 2 в пуле.
- 3–20 игроков.
- Без ведущего: сервер сам выбирает героя и шпиона.
- Каждый игрок получает секретную карточку только через своё соединение.
- Node.js 18+ и WebSocket.

Запуск:
1. `npm install`
2. `npm start`
3. открыть `http://localhost:3000`

Для игры через Discord нужен публичный HTTPS/WSS-хостинг Node.js (например Render/Railway/Fly.io). GitHub Pages здесь не подходит, потому что игре нужен WebSocket-сервер.
